Account approvals & roles

Approve verified signups, activate club membership and assign roles. These controls are restricted to the separately bootstrapped platform administrator.

Verifying platform administrator access…

Registered accounts

Only email-verified accounts can be approved. Approval grants club membership and the selected role; an Auth account alone has no club access.

Security boundaries

  • Platform admin authority is stored in a private database table and cannot be granted through this page.
  • Every approval and role change is checked and audited by trusted backend functions.
  • Only one active Chairman is allowed. Existing Chairman role revocation must use a controlled handover workflow.
  • Role assignment does not by itself implement permissions for unfinished club modules.
